# AI Career Assistant

A simple AI-powered career guidance chatbot built with Python and Ollama. It answers career-related questions using the Llama 3.2 (1B) language model and a custom system prompt designed to provide practical, beginner-friendly advice.

## Features

- Provides career guidance and learning recommendations.
- Explains career paths, required skills, learning roadmaps, and interview preparation.
- Uses a custom system prompt to define the AI assistant's role and behavior.
- Accepts questions through a terminal-based interface.
- Supports multiple questions in a single session.
- Handles empty user input.
- Allows users to type `exit` to end the conversation.

## Technologies Used

- **Python 3.13.6** — Application logic and user interaction.
- **Ollama** — Runs and provides access to the local AI model.
- **Llama 3.2 (1B)** — Generates career-related responses.
- **Requests** — Sends HTTP requests from Python to the Ollama API.

## Prerequisites

Before running the project, make sure you have:

1. Python installed.
2. Ollama installed and accessible from your terminal.
3. The Llama 3.2 (1B) model downloaded.
4. An internet connection for initial software and model downloads.

## Installation and Setup

### 1. Install Python

Download Python from the official website:

https://www.python.org/downloads/

Verify the installation:

```bash
python --version
```

The project was developed using Python 3.13.6.

### 2. Install Ollama

Download and install Ollama for Windows:

https://ollama.com/download/windows

Verify the installation:

```bash
ollama --version
```

The development environment used Ollama 0.40.11.

### 3. Download the AI Model

Run the following command in your terminal:

```bash
ollama run llama3.2:1b
```

This downloads the model if it is not already available and starts an interactive chat. After confirming that the model works, type `/bye` to exit.

You can verify that the model is available with:

```bash
ollama list
```

### 4. Install Python Dependencies

Open a terminal in the project directory and run:

```bash
python -m pip install requests
```

The `requests` library allows Python to send HTTP requests to the Ollama API.

## How to Run

1. Open the project folder in VS Code or another code editor.
2. Open a terminal in the project directory.
3. Ensure Ollama is running and the model is available.
4. Run the application:

```bash
python career_assistant.py
```

5. Enter a career-related question when prompted.
6. Read the AI-generated response in the terminal.
7. Ask additional questions or type `exit` to close the application.

## How It Works

### 1. System Prompt

The `SYSTEM_PROMPT` variable defines the assistant's role and behavior. It instructs the AI to provide practical, beginner-friendly, clear, and professional career guidance.

### 2. User Input Handling

Python's `input()` function receives questions from the user. The program removes surrounding whitespace, checks for empty input, and recognizes the `exit` command.

### 3. Communication with Ollama

The `get_career_response()` function sends an HTTP POST request to Ollama's local chat API:

```text
http://localhost:11434/api/chat
```

The request includes the model name, system prompt, user question, and the setting `"stream": false`.

### 4. Response Processing

The program checks the HTTP response status, extracts the generated answer from the JSON response, and displays it in the terminal.

## Troubleshooting

**Ollama command is not recognized**

- Ensure Ollama is installed.
- Restart your terminal after installation.
- Verify that the Ollama command is available.

**Connection error when asking a question**

- Ensure the Ollama application or service is running.
- Check that the model is available using `ollama list`.
- Confirm that the API address is `http://localhost:11434/api/chat`.

**Model not found**

Run:

```bash
ollama pull llama3.2:1b
```

Then try running the Python program again.
